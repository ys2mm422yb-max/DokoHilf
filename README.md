# DokoHilf

DokoHilf ist eine unabhängige interne Schritt-für-Schritt-Hilfe für Dokumentationsabläufe.

## Start für jeden neuen Chat

Vor jeder Arbeit sind diese Dateien vollständig zu lesen:

1. [`PROJECT_RULES.md`](./PROJECT_RULES.md) – verbindliche Sicherheits-, Datenschutz- und Projektregeln
2. [`PROJECT_HANDOFF.md`](./PROJECT_HANDOFF.md) – aktueller Stand, Architektur, Entscheidungen und offene Arbeiten
3. [`CONFIRMED_WORKFLOWS.md`](./CONFIRMED_WORKFLOWS.md) – alle fachlich bestätigten, anonymisierten Klickwege und Sonderregeln
4. anschließend tatsächlichen GitHub-, Actions-, Pages- und Supabase-Stand prüfen

Die Übergabe und die bestätigten Arbeitsabläufe sind dauerhaft im Repository zu pflegen, damit ein neuer Chat nicht wieder bei null beginnt.

Öffentlich sichtbare Projektinhalte beschreiben ausschließlich selbst formulierte, anonymisierte und veröffentlichungsfähige Ergebnisse. Herkunft, Prüfmaterialien oder interne Ausgangsmaterialien werden nicht öffentlich dokumentiert.

## Aktueller Stand

- eigenständiges GitHub-Repository
- getrenntes Supabase-Projekt in Frankfurt
- ausschließlich synthetische Test- und Platzhalterdaten
- dauerhaft keine realen Bewohner-, Gesundheits- oder Mitarbeiterdaten
- keine Logos, kopierten Handbücher oder geschützten Schulungsunterlagen
- zustandsbasierte, redaktionell freigegebene Schritt-für-Schritt-Anleitungen
- PWA-Veröffentlichung über `main` und den tatsächlich ausgelieferten Branch `gh-pages`

## Projektgrenzen

Dieses Repository darf nicht mit anderen GitHub- oder Supabase-Projekten vermischt werden. Öffentliche Inhalte dürfen ausschließlich neutral, selbst erstellt, anonymisiert und veröffentlichungsfähig sein.
